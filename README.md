# obstacle-avoidance-robot
Arduino obstacle avoidance robot with ultrasonic sensor and servo


## Overview

This project is an arduino based obstacle avoidance robot that uses an HC-SR04 ultrasonic sensor mounted on a servo motor to scan the environment. The robot measures the distance in front, then looks left and right when an obstacle is detected, Based on the measured distance, it chooses the clearer path and continues moving forward. A push button is used for start stop control and a LED indicates the robot operating state.

This project is part of my level 1 Arduino and Robotics course designed for beginners.
